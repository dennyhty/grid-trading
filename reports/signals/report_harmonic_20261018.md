# 諧波型態回測（2026-10-18）

Denny 看了 Threads 上的鯊魚諧波，想知道鯊魚、蝙蝠這類諧波策略的績效。我把 9 種常見型態寫成固定規則，用幣安 USDT 永續的資料回測（2020-01 到 2026-09，84 個幣，1H / 4H / 日線）。程式在 `research/harmonic_strategies.py`。

## 結論

**沒有一個諧波型態值得做。** 9 種型態 × 3 個週期 × 3 種轉折靈敏度 × 4 種出場，筆數夠多（100 筆以上）的組合有 180 個，中位數是每筆 −0.11R，沒有一個組合的 t 值超過 2。加上日線 EMA200 順勢濾網也一樣（136 個組合，只有 2 個是正的，而且接近 0）。

- 出現最多的鯊魚和 AB=CD，在每個週期、每段期間都穩定虧錢（每筆 −0.08R 到 −0.15R）。
- 帳面上唯一是正的深螃蟹：4H 每筆 +0.11R（277 筆，t 1.2）、日線 +0.30R（只有 44 筆）。樣本太小，而且一次測了這麼多組合，冒出一兩個正的本來就是運氣能解釋的。
- 勝率幾乎都在 42–52%，沒有一個高勝率的型態。

## 規則

- **找轉折：** 用 ATR 門檻的 zigzag，價格從高點或低點反向走超過 2、3、5 倍 ATR 才算一個轉折，只用已收盤的 K 棒。
- **型態比例**（Scott Carney 的標準值；X、A、B、C 是最後四個轉折，D 是進場點）：
  - 加特利：AB = 0.618 XA、D = 0.786 XA，停損在 X。
  - 蝙蝠：AB = 0.382–0.5 XA、D = 0.886 XA，停損在 1.13 XA。
  - 另類蝙蝠：AB ≤ 0.382 XA、D = 1.13 XA，停損在 1.27 XA。
  - 蝴蝶：AB = 0.786 XA、D = 1.27 XA，停損在 1.414 XA。
  - 螃蟹：AB = 0.382–0.618 XA、D = 1.618 XA，停損在 1.902 XA。
  - 深螃蟹：AB = 0.886 XA、D = 1.618 XA，停損在 1.902 XA。
  - Cypher：C 超過 A 達 XA 的 1.13–1.414、D = XC 的 0.786，停損在 X。
  - 鯊魚：B 超過 X 達 XA 的 1.13–1.618、D = OX 的 0.886，停損在 1.13 OX。
  - AB=CD：BC = 0.382–0.886 AB、CD = AB，停損在 1.27 AB。
  - 前六種另外要求 BC = 0.382–0.886 AB，CD 是 BC 的合理延伸（例如加特利 1.13–1.618、螃蟹 2.24–3.618）。
- **進場：** C 確認後在 D 掛限價單；下一個轉折出現，或 100 根內沒成交就取消。確認時價格已經越過 D 就不追。停損外再加 0.1 ATR。
- **成本：** 手續費每邊 0.05%。成交那根同時碰到停損一律算停損。同一個幣、同一個型態同時只持有一張。

## 為什麼不行

諧波的進場點都在「前一段走勢的延伸或深回撤」，本質上是逆勢抄底摸頭。我們之前測過的反轉類策略（RSI/MACD 背離、外包日、均值回歸）也都輸，加密貨幣的趨勢通常會直接穿過這些比例位置。
