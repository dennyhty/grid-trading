- 反過來 2H 改用 4H 那套明顯變差，所以統一要統一成 2H 那套。

## 2. 同一個幣 2H、4H 同方向只做一張

規則：同一個幣、同方向，另一個週期的單還沒出場，新訊號就不做（先出的那張留著）。幣安全期，現在的出場：

| | 兩張都做 | 只做一張 |
|---|---|---|
| 交易數 | 9229 | 7908（少 14%） |
| 每筆平均 R | +0.158 | +0.143 |
| 每年總 R | 219 | 170（少 22%） |
| Sharpe | 1.67 | 1.62 |
| 最大回撤 | −39.5% | −35.5% |
| 最差的一天 | −37R | −31R |

派網：Sharpe 1.38 → 1.39，回撤 −34% → −29%，每年總 R 少 19%。

讀法：被擋掉的第二張平均是賺的（約 +0.25R），所以總獲利少了約兩成；回撤和最差一天也小了，風險調整後（Sharpe）差不多。
效果接近「把部位調小一點」，不是讓策略變好，但是能避免同一筆行情下兩次。
