# 候選 B 延伸：現貨補長到 2017、改用等權幣池指數對沖（2026-10-20）

目的：回答 [report_candidates_20261020.md](report_candidates_20261020.md) 對候選 B（每週橫斷面動能／低波動多空）的兩個疑問：(1) 樣本內只有 2020-23 一個多空循環，太短；(2) 獲利是不是只是「BTC 對沖輸給大型山寨」。用幣安現貨把資料往前補，比較三種對沖：BTC、等權幣池指數、不對沖只做金額中性。成本與 PR #53 相同：手續費每邊 0.05%、依 30 天日均成交額分級的滑價、合約期用幣安歷史資金費率、一週一個標準差 = 帳戶 0.25%。

程式：`grid_trading/spot_pit_universe.py`（現貨時點幣池）、`research/candidates_xsec_ext.py`（接縫面板、三種對沖）、`research/candidates_xsec_ext_run.py`（跑法）；測試 `tests/test_xsec_ext.py`。明細 CSV：`xsec_ext_grid / gate / corr / yearly / coins / spot_pool_20261020.csv`。重跑：`python -m research.candidates_xsec_ext_run`（約 2 分鐘；不要加 `--log`，會重複寫帳本）。

- **補長的幫助比預期小**：2018 年 7 月前合格的 USDT 現貨交易對不到 10 個，所以「2017-09 起」實際是 2018-07-30 起，現貨期只有 525 天，幣池 14～75 個。
- **改用指數對沖每一段都變好**（舊樣本內 +0.18 → +0.50，2023 年 −33% → −17%）。原因：BTC 對沖腿全期 −134R，指數對沖腿 +12R，證實 PR #53 的懷疑：BTC 對沖賠的錢，是 2020-26 年 BTC 比整個幣池強的行情。
- **但樣本外變好不是新證據**：改用指數對沖的想法來自 PR #53「BTC 對沖虧 139R」的全期拆解，已包含樣本外。真正沒看過的新資料只有現貨期，而它的獲利主要來自空單（+90R，多單 −52R），當時大多數幣根本放空不了。
- **指數中性不等於 BTC 中性**：主設定與 BTC 日相關 +0.25（做多低波動大型幣，做空高波動小幣），有一部分是大型對小型的規模暴露。
- **分散效果仍是真的**：和維加斯日相關 +0.009、月相關 −0.18；合併夏普 2020 起 1.27 → 1.50，樣本外 1.01 → 1.44。

## 資料與接縫

- 現貨幣池（2017-09 ~ 2019-12）：上個月現貨 USDT 成交額前 min(100, 可選) 名，上個月至少 20 天有量；含已下架的幣；排除穩定幣／法幣與槓桿代幣。池子大小：2018-01 5 個、2018-07 14 個、2019-01 19 個、2019-06 39 個、2019-12 75 個。
- 現貨與合約當成不同商品，2020-01 第一個週日現貨部位全部平倉並付成本；2020-01-06 ~ 2020-03-22 空手（與 PR #53 相同）。
- 現貨期沒有資金費率（設為 0），當時多數幣無法放空，所以是**紙上多空組合**；現貨手續費實際 0.075～0.1%，用 0.1% 重算現貨期夏普 0.99 → 0.88。
- 等權指數對沖：以當月幣池等權平均日報酬估 60 天 beta；對沖是這次合格的所有幣各放等額反向部位的一籃子，成本逐幣計算且不與多空腿抵銷（偏保守）。

## 建議

1. **不上測試網、不投入資金。** 證據比 PR #53 強，但離門檻還很遠。
2. **零資金影子紀錄：勉強值得，只當「實作檢查＋前瞻樣本」，不當驗證。** 理由：三段期間方向一致、8 組樣本外全正、與維加斯零相關、每週只動一次。但真實夏普若 0.5～0.9，要累積到 t = 2 需要 5～16 年，影子紀錄幾乎一定「看不出來」。條件：凍結 combo|q0.3|index、每週日收盤、全自動且維護成本近零、至少 12 個月、滾動 26 週夏普 < 0 或回撤 > 25% 就停、影子期好看不能跳過關卡。
3. 實作問題：指數籃子約 100 個幣，在這個風險大小下每個幣只有帳戶的萬分之幾，會碰到幣安最小下單金額；實盤只能把籃子與多空腿合併淨額，或用少數大型幣近似。影子紀錄要先確認。
4. 這個家族不要再加變形：8 組已回答主要問題，再試只增加試驗數。

## 已知限制

- 現貨期實際只有 2018-07-30 ~ 2020-01-05（525 天）；現貨期空單當時多數做不到。
- 指數 beta 用每天再平衡的等權指數估，對沖工具是每週再平衡的籃子，略有不同。
- 滑價分級是假設值。
- 樣本外 2024+ 在 PR #53 已看過，指數對沖的想法也來自含樣本外的全期拆解，所以 +1.37 不是乾淨的樣本外。
